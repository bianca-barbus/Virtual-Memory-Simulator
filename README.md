# Virtual-Memory-Simulator
The aim of this project is to simulate the main operations that can be performed in case of a
virtual memory: finding the information, placing a page in the main memory, replacing a page. Virtual
memory allows a computer system to run processes larger than the available physical memory.
However, the management of virtual memory comes with complexities such as page faults, page
replacement strategies and address translation.

This simulator can be used to visualize how various strategies, algorithms used in virtual memory,
function and giving the user the possibility to understand how it impacts system efficiency.
